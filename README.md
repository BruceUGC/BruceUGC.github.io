# Programmer Portfolio

A responsive, static portfolio site built with HTML, CSS, and vanilla JavaScript. No build step or package installation required.

## 1. Personalize the site

Open `index.html` and replace these placeholders:

- `YOUR NAME` — your display name
- `YOUR-USERNAME` — your GitHub username
- `YOUR-LINKEDIN` — your LinkedIn profile slug
- `YOUR CITY` — your location (or remove the location line)
- `hello@example.com` — your public contact email

Update the three sample project cards with your real projects, stack, repository links, and demos. Remove any cards you don't need. Update the title and description in the `<head>` too.

## 2. Preview locally

Open `index.html` in a browser. For a more realistic local preview, use the Live Server extension in VS Code. The site does not need Node, npm, or a server-side backend.

## 3. Publish with GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io` for a personal site (replace the placeholder with your GitHub username).
2. Upload the contents of this folder to the repository's root. Make sure `index.html` is at the root, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. Your site will be at `https://YOUR-USERNAME.github.io/`.

If you use a repository with another name, GitHub Pages will publish it as a project site, usually at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Before you publish

- Replace every placeholder and sample project.
- Check every project, social, and email link.
- Do not commit passwords, API keys, private information, or confidential work. A published Pages site is public.
- Use only projects and images you have permission to show.
